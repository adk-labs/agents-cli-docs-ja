# このプロジェクトについて

## フィードバック

私たちは皆様のご意見を重視しています — それによりコミュニティのために `agents-cli` を改善できます。

- **問題報告およびご提案:** GitHub で [issue をオープンする](https://github.com/google/agents-cli/issues)
- **体験の共有:** [agents-cli@google.com](mailto:agents-cli@google.com) までお問い合わせください

## 貢献方法

最も効果的な貢献方法はフィードバックを提供することです: バグ報告、機能リクエスト、および [issues](https://github.com/google/agents-cli/issues) を通じて共有されたアイデアは、ロードマップの策定に直接役立てられます。
